家伴助手 Kinloop · 浅色全景架构

传统家庭业务与 AI Agent 同级共存：业务沉淀可信用户数据，Agent 提供智能增强与效率提升

SubAgent 调度

  • • Planner 是唯一对外 Agent 入口，默认后台派工
  • • 七个专业 Agent 均由中间件委派（Usage 已退役）
  • • MCP 在 SubAgent spawn 时握手并过滤工具

基础依赖重点

  • • PostgreSQL 承载业务、治理、用量和 Agent 状态
  • • Restate 承载任务、知识双写和耐久调度
  • • Qdrant 是权威知识库，Mem0 仅增强召回

故障与回退

  • • 知识读取失败时回退 ragent MCP
  • • Mem0 召回 / observe 失败放行普通对话
  • • Media 缺 Key 降级；调用有 eval 行为门禁
